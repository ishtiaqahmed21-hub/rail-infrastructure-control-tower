# Dashboard deliverables

Open index.html locally: six navigable pages with actual generated analysis charts, accessible descriptions and CSV links. dashboard_prototype.png is a labeled, programmatically rendered overview of the same six panels; it is not a Power BI screenshot. The repository contains an implementation-ready Power BI/Tableau specification, not a native PBIX/TWB workbook. No server, credentials or external assets are required. Regenerate charts and HTML with python -m src.pipeline.
